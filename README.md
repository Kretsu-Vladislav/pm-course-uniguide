# UniGuide

**UniGuide** — вебплатформа менторства, яка допомагає першокурсникам адаптуватися до університетського життя за підтримки досвідчених старшокурсників.

## Основна мета

Створити зручне середовище для взаємодії першокурсників і старшокурсників, у якому нові студенти зможуть знаходити менторів, отримувати поради та швидше адаптуватися до навчання в університеті.
